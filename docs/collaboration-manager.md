# 협업 매니저

회원마다 협업 조건, 일정, 결과물, 입금·지출, 완료·취소 이력을 저장합니다. 보관함 다음 메뉴이며 주소는 `#collaborationView`입니다. 기록은 본인만 접근할 수 있고 운영 관리자도 다른 회원의 내용을 조회할 수 없습니다.

## 자동 분류

메일 본문을 붙여넣거나 PDF, DOCX, TXT, MD, HTML, 텍스트 EML 파일을 가져옵니다. 브라우저에서 규칙 기반으로 항목을 추출한 뒤 검토 화면을 엽니다. 유료 AI 호출은 없습니다. 인식 근거와 확인할 항목을 표시하며, 저장 전에는 원문을 서버에 보내지 않습니다. 원본 파일이 아닌 추출한 텍스트를 기록에 보관합니다.

파일은 5MB 이하, PDF는 40페이지 이하, 원문은 50,000자 이하입니다. 이미지·스캔 PDF 및 HWP에는 OCR 기능이 없으며 텍스트로 변환하거나 본문을 붙여넣어야 합니다. 암호화·MIME 인코딩 메일 파일도 본문 붙여넣기를 안내합니다. 표기와 문장에 따라 누락될 수 있으므로 날짜·금액·결과물 수량은 저장 전에 확인해야 합니다.

자동 분류한 초안에는 저장 버튼 위에 날짜·금액 확인란이 표시됩니다. 원문과 비교했다고 체크해야 최초 저장할 수 있으며, 날짜·금액 수정 또는 결과물 추가·삭제 시 확인이 해제됩니다. 수동 신규 작성 및 기존 기록 수정에는 이 확인란이 표시되지 않습니다.

## 일정 달력

진행 중인 협업 목록 아래와 ‘일정 모아보기’에 월간 달력이 표시됩니다. 방문·예약, 원고 제출, 발행 마감, 결과물별 마감, 정산 예정을 색과 이름으로 구분합니다. 완료한 일정도 연하게 표시하며 취소·휴지통 기록은 제외합니다. 달력은 목록의 페이지 번호와 관계없이 전체 기록을 대상으로 검색어·상태 필터를 적용합니다. 한국시간 기준이며, 월 이동·오늘 이동·날짜별 전체 일정 확인·협업 상세 열기를 지원합니다. 모바일에서는 날짜별 건수와 색상 표시를 누르면 아래에서 일정을 읽을 수 있습니다. 목록의 제공가·지출은 현금 원고료·정산과 별도 표시합니다.

## 정산

제품·서비스 제공가는 현금과 분리합니다. 약정 현금 원고료에서 실제 공제액과 입금 합계를 차감해 미입금액을 계산하며, 지출은 별도로 기록합니다. 공제액은 사용자가 입력하며 세액을 자동 계산하지 않습니다. 완료·취소해도 금액 기록은 유지되고, 휴지통으로 이동한 기록은 요약에서 제외됩니다.

## 리마인드 메일 연결

Supabase Auth의 SMTP와 별도 연결입니다. API 관리 권한이 있는 관리자가 관리자 설정의 ‘협업 리마인드 메일 연결’에 Gmail 주소와 16자리 Google 앱 비밀번호를 직접 입력합니다. 서버는 SMTP TLS 465 연결을 검증한 뒤 Vault에 암호화 저장합니다. 비밀번호는 조회 API나 화면으로 반환하지 않습니다. 테스트 메일은 해당 관리자의 인증 이메일로만 발송합니다.

회원이 협업의 ‘일정·알림’에서 알림을 켜야 예약됩니다. 인증된 회원 본인의 이메일로만 전송하며 업체·담당자에게 보내지 않습니다. 한국시간 기준 당일/1일/3일/7일 전과 발송 시간을 설정할 수 있습니다. 매 5분 처리하며, 전체 하루 200개·계정별 하루 10개 일정까지 처리합니다. 등록 시 이미 지난 알림 시각은 소급 발송하지 않고, 24시간 이상 지난 예약은 만료 처리합니다. 발송 실패 시 연결을 중지하고, 결과가 불확실한 발송은 중복 방지를 위해 자동 재시도하지 않습니다. 실제 배달 여부는 테스트 메일 수신으로 확인해야 합니다.

취소, 휴지통 이동, 알림 해제 시 예약을 취소합니다. 전체 상태가 발행·완료면 콘텐츠 일정 알림을 중지하며 정산은 미입금액이 남아 있을 때만 유지합니다. 개별 결과물이 발행되면 그 결과물의 알림은 중지됩니다. 발송 직전에 취소해도 이미 메일 서버에 전달된 메일은 회수할 수 없습니다.

## 구현과 검증

- `collaboration.js`, `collaboration.css`: 목록, 상세 편집, 검토, 정산, 관리자 연결 화면
- `collaboration-import.js`: 파일 읽기와 필드 추출. 라이브러리는 `vendor/collaboration`에 버전 고정
- `supabase/functions/keyon-collaboration-mail/index.ts`: 회원 JWT/관리자 권한 또는 전용 스케줄러 토큰 검사 후 발송
- `supabase/migrations/20261028*collaboration*.sql`: 회원별 RLS, 변경 이력, 예약 중복 방지, cron, Vault 연결
- `node --test tests/collaboration.test.mjs`: 금액·날짜·다중 결과물·검토 동작 검증
- `node scripts/build.mjs`: 정적 배포 파일 생성

운영 DB 테스트는 트랜잭션을 롤백하여 검증 기록을 남기지 않습니다. RLS의 다른 계정 읽기·쓰기 차단, 비밀키 조회 차단, 버전 증가, 알림 중복 방지와 발행·입금 시 취소를 확인합니다.
